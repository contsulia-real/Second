# Second 项目与募资说明

2026-10-09 · 首次接触草稿 · 金额与出资条件尚未确定

## 项目是什么

Second 是独立的数字货币状态与授权任务执行网络，Secoin 是当前讨论中对网络货币的称呼。外部授权系统签发 LegalTask，网络验证授权和可执行性，完成确定的货币状态变化，并保障业务原子性、幂等性、并发安全和最终性。

钱包、交易设施、支付服务、商业担保和业务审批属于外部设施。Second 不统一规定这些设施的商业模式，也不承诺法币兑付或货币价格。当前实现使用 Validator 本地 AuthorizerSet 验证签发者；验证者参与也有准入约束，不能描述为已实现任意签发者或验证者无需准入的网络。

## 技术方向与已有交付

Second 围绕实际对象的 ConsensusScope 建立共识，使用 Currency ownership 作为唯一资产真值。工程目标是在保持安全和最终性的前提下减少无必要的全局排序、复制、传播和重复计算。目前没有与 BTC、Ethereum 或 Solana 的同条件性能、能耗比较，相关优势需要独立测量。

截至当前记录，已确认的内部协议、CLI、节点及 Windows/WSL 支持范围已完成开发验收：

- Windows 与 WSL Linux 两端连续两轮默认全量测试通过，每端每轮 344 项；格式、编译与严格静态检查通过。
- 固定 Release 产物组成的四进程混合集群，持续段运行 601 秒、完成 134 笔转账，覆盖轮流停机、必要 quorum、重启补齐、最终共享状态一致和旧请求幂等。
- Windows SCM 与 Linux systemd 实际服务生命周期通过，包括安装、停止、重启、异常终止恢复及卸载保留数据。

这些结果证明了所列工程范围的行为，不代表商业采用、第三方审计通过、长期主网运行或任意负载能力。Windows/WSL 验收在同一物理主机上完成，独立物理主机网络尚未验证。
